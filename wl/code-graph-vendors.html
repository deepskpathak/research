Code Graph Vendors: Landscape, Shortlist and Use Cases

Research date: 2026-11-18 | Scope: industry and open-source code graph tools that serve AI agents, change campaigns, code review and knowledge graphs

How to read this

  • Every fact carries a numbered source. Lines marked Assessment are my analysis, not sourced facts.
  • Vendor-reported means the number comes from the party selling or building the tool. Independent benchmarks are rare.
  • GitHub stars and forks were read from the GitHub REST API on 2026-11-18 at 02:06 UTC, and each figure links to its repository.
  • "Generative agents" is read here as AI coding agents that generate code (Claude Code, Codex, Cursor and similar).

1. Summary

Bottom line (Assessment): no single vendor covers all four use cases well. The pattern that fits the evidence is a layered stack: a precise, persistent code graph as the corpus, an SDLC graph for merge request and pipeline context, and a deterministic transformation engine for campaigns, all served to agents over MCP.

What changed in 2026

  • Code graphs became agent infrastructure. Sourcegraph 7.0 (Feb 2026) repositioned the product as a shared intelligence layer for developers and AI agents [1]. GitLab Orbit went GA on 29 Oct 2026 [2]. Moderne now calls itself "the Agent Tools company" [3].
  • MCP is the delivery channel. Orbit exposes query_graph and get_graph_schema [4], Sourcegraph serves search, navigation and Deep Search over MCP [5], and Moderne ships its LST engine and Moddy agent over MCP [6].
  • Open-source local graphs exploded. CodeGraph, created in Jan 2026, has 77,889 stars [7], and codebase-memory-mcp, created in Feb 2026, has 48,789 [8].
  • SCIP became a shared standard. SCIP moved to open governance in March 2026 with a steering committee that includes engineers from Meta and Uber [9].

What the evidence says

  • Graphs help on multi-hop questions. In KGCompass, 89.7% of the bugs it localized had no location hint in the issue and were found only through multi-hop graph traversal [10].
  • Agents often ignore the graph. In CodeCompass, 58% of trials with graph access skipped the graph tool despite explicit instructions [11].
  • Graph grounding costs more per call. In Compare the Market's test, the Orbit-grounded reviewer cost $2.37 per merge request versus $0.58 for diff-only review [12].

2. Key terms

  • Code graph: nodes for files and symbols, edges for calls, imports and definitions. Orbit, for example, indexes files, directories, definitions, imports and calls [13].
  • SCIP: a language-agnostic protocol for indexing source code that powers go-to-definition and find-references [14].
  • Code property graph (CPG): a graph for mining large codebases for programming patterns, queried with a Scala-based DSL [15]. It merges a syntax tree, a control-flow graph and a program-dependence graph [16].
  • Lossless Semantic Tree (LST): OpenRewrite's code tree that keeps whitespace, so it can print back the original source without reformatting [17]. It is type-attributed [18].
  • Context graph (SDLC graph): a code graph joined with lifecycle data. Orbit maps code, work items, pipelines, deployments and production signals into one graph [19]. Graphiti's context graphs also record when each fact became true and when it was superseded [20].
  • MCP: the Model Context Protocol, which every shortlisted tool uses to serve agents [4, 6, 7, 21].

3.4 Common usage patterns

  1. Local stdio MCP server beside the agent. CodeGraph, codebase-memory-mcp and Orbit Local all run on the developer's machine [7, 8, 23].
  2. Shared remote MCP endpoint over an org-wide index. Sourcegraph serves /.api/mcp from its instance [21]; Orbit Remote spans a top-level GitLab.com group [23].
  3. Index in CI. Sourcegraph recommends running SCIP indexing in CI for complex builds [62]. Compare the Market ran Orbit as a sidecar that re-indexed on each MR pipeline [12].
  4. Review bot with a private graph. Greptile builds a graph at sign-up and queries it on every review [63].
  5. Campaign engine. Sourcegraph Batch Changes opens and tracks PRs across many repos [64]; Moderne runs recipes across thousands of repos [65].
  6. Push context with hooks and skills. GitNexus registers Claude Code hooks and writes AGENTS.md and CLAUDE.md files [45]; codebase-memory-mcp installs skills, agent profiles and hooks [8].

4. Shortlist deep dives

Four industry vendors and four open-source tools, picked for fit with the four use cases and for traction.

4.1 Sourcegraph (industry)

What it is: a code understanding platform that 7.0 repositioned as a shared intelligence layer for developers and agents [1].

Features

  • Indexes every repository, branch, tag and revision across GitHub, GitLab, Bitbucket, Gerrit, Perforce and Azure DevOps [5].
  • Structural, semantic and regex search, plus commit, diff and blame history [5].
  • Cross-repo go-to-definition and find-references out of the box [5].
  • Deep Search: agentic natural-language exploration on the same index [5]. 7.0 improved its accuracy, added image support and embedded code navigation [1].
  • Batch Changes: creates PRs on every affected repo and tracks them until merged [64]. Agentic Batch Changes adds AI-generated, reviewable changes across thousands of repos [5].

Technology

  • Precise navigation uses per-language SCIP indexes uploaded to the instance [62], with search-based navigation as the fallback [66].
  • SCIP is optional, and Sourcegraph says search, navigation, Deep Search and MCP work without it [5].

Usage patterns

  • Agents connect to /.api/mcp, with /.api/mcp/all and /.api/mcp/deepsearch as alternate tool suites [21].
  • Authentication is OAuth 2.0 (including Dynamic Client Registration) or access tokens [21].
  • Campaigns are YAML batch specs naming target repos, commands and changeset templates [64].

Deployment and price

  • Enterprise Dedicated Cloud is the default and Enterprise Self Hosted is on request, both listed at $59 per user per month [22].
  • Self-hosting runs on Kubernetes with Helm (recommended) or Docker Compose [67].

Watch-outs

  • MCP server is an Enterprise plan feature [21].
  • Precise data needs a working indexer per language, and Sourcegraph recommends CI indexing for authenticated builds [62].
  • Assessment: the fetched pages describe code and version history, not pipelines, deployments or vulnerabilities, so SDLC context would come from elsewhere.

4.2 GitLab Orbit (industry)

What it is: formerly the GitLab Knowledge Graph, a Rust service that builds a property graph from SDLC metadata and code, queried with a JSON Cypher-like DSL compiled to ClickHouse SQL [68]. GA on 29 Oct 2026 [2].

Features

  • Indexes default-branch code (files, directories, definitions, imports, calls) plus merge requests, pipelines, vulnerabilities and branches [13].
  • Code languages: Ruby, Java, Kotlin, Python, TypeScript, JavaScript, Rust, Go, C#, C, C++, PHP, Bash and Elixir [23].
  • Hosted DSL supports aggregations, traversals, neighbors and pathfinding [23].
  • File content is resolved at query time, so agents can read code without a second API call [69].

Technology

  • Orbit Remote: gkg-server on ClickHouse, fed by change data capture through GitLab's Data Insights Platform [23].
  • Orbit Local: a single-binary orbit CLI on DuckDB with a stdio MCP server [23].

Usage patterns

  • Agents connect through MCP or glab orbit setup; named clients include Claude Code, Codex, Cursor, OpenCode, Gemini CLI and Antigravity [2].
  • Native in Duo Agent Platform, REST for custom agents, and Data Explorer for engineers [2].
  • REST endpoints: /api/v4/orbit/query, /schema, /status and /tools [70].

Pricing and availability

  • Premium and Ultimate. GitLab.com first; Self-Managed and Dedicated follow in the coming weeks [2].
  • Query packs of $30 in GitLab Credits per user per month add 1,000 queries to an org-wide pool; overage is about $0.03 per query [2].
  • get_graph_schema calls are free, while queries consume credits [71].

Scale and claims (vendor-reported)

  • More than 1.5 million projects and 8 TB of graph data indexed in under 2 hours [2].
  • Up to 11x faster responses and 4.5x fewer tokens [19]; up to 45x fewer retries [2].

Watch-outs

  • Only the default branch is indexed [13].
  • License is the GitLab Enterprise Edition license, not open source [23].
  • Some MCP clients truncate the long query_graph description, so models miss the DSL grammar [72].
  • In the pre-GA Compare the Market test, latency was 80.6 s versus about 44 s for diff-only review [12].

4.3 Moderne and OpenRewrite (industry with open-source core)

What it is: OpenRewrite is an open-source semantic analysis and refactoring project [52]; Moderne adds tooling to run its recipes against thousands of repositories at once [65].

Features

  • Recipes search and transform code represented as LSTs [25].
  • Moddy: a multi-repo AI agent, in restricted beta, that runs across thousands of repositories [73].
  • Prethink (launched 10 Feb 2026 [74]): pre-resolved context for agents on service endpoints, database connections, external calls, messaging patterns and test coverage [75]. It can also emit an optional knowledge graph and FINOS CALM architecture diagrams [76].
  • Changelog (May 2026): shows what is ready, blocked or waiting across a changeset, through MCP and GraphQL [3].
  • Trigrep: symbol-aware code search for agents [3].

Technology

  • Run locally, the LST must fit in memory [17]. Moderne serializes LSTs as a build byproduct and edits them in bulk later [65].
  • Python support was added in Feb 2026 [77].

Usage patterns

  • Delivered as the LST engine, recipe catalog, CLI, IDE plugins and Moddy, over MCP to coding agents [6].
  • Positioning: the agent plans while Moderne's deterministic tools execute [6].
  • Moddy Desktop runs an MCP server at localhost:4848/mcp [78].

Traction

  • $30M Series B (Feb 2025) with Morgan Stanley, Amex Ventures and TIAA Ventures participating [79].
  • OpenRewrite is integrated into Amazon Q and Broadcom App Advisor [79].

Watch-outs

  • Moddy is still restricted beta [73].
  • Assessment: strongest on JVM ecosystems; check recipe coverage for each language and framework you plan to migrate.

4.4 GitHub CodeQL (industry)

What it is: GitHub's semantic code analysis engine, which queries a codebase as though it were data [29].

Features

  • Copilot Autofix suggests fixes for CodeQL alerts. It is on by default for repos using CodeQL and needs no Copilot subscription [80].
  • Autofix runs on pull requests and on the default branch [81].
  • Copilot code review now blends LLM detection and tool calling with CodeQL and ESLint [82]. CodeQL is on by default; ESLint and PMD are off [30].
  • Data-flow libraries can be extended with sources and sinks for extra frameworks [83].

Technology and languages

  • Supports C/C++, C#, Go, Java/Kotlin, JavaScript/TypeScript and more; it does not support PHP or Scala [84].
  • Standard queries are open source in github/codeql [32].

Usage patterns

  • Default setup picks languages, query suite and trigger events automatically [84].
  • Code scanning runs on public repos, and on org repos with GitHub Code Security enabled [85].

Watch-outs

  • Without GitHub Advanced Security, the CodeQL CLI may only be used on open-source codebases [31].
  • Assessment: CodeQL is a deep analysis database, not a general MCP-queryable code graph; it fits review and security, less so agent navigation on GitLab-hosted code.

4.5 CodeGraph (open source)

What it is: a pre-built graph of every symbol, call edge and dependency, so an agent gets the code it needs in one call [7].

  • Tech: Rust parsing kernel for 20 languages; local SQLite with FTS5; no data leaves the machine [7].
  • Interface: one default MCP tool, codegraph_explore, with narrower tools available but unlisted [7].
  • Freshness: watches the project and updates the graph on every file change [7].
  • Benchmark (vendor-reported): across 7 repos on Claude Opus 4.8, 88% fewer tool calls, 53% faster, 62% fewer tokens and 44% cheaper [7].
  • Honest caveat: multi-turn sessions keep about 80% more retrieval context resident in the window [7].
  • Roadmap: a hosted PR platform is announced as coming [7].

4.6 codebase-memory-mcp (open source)

What it is: a persistent local knowledge graph that connects code, documentation, configuration and infrastructure [8].

  • Tech: native C backend with 17 MCP tools, vendored grammars and hybrid LSP type resolution [8]; the preprint stores the graph in SQLite and uses Louvain community detection [86].
  • Beyond code: traces Docker, Kubernetes, Helm, Terraform, Ansible and CI configuration [8].
  • Scale: the Linux kernel (28M lines) fully indexes in 3 minutes into 4.81M nodes and 7.72M edges on an Apple M3 Pro [8].
  • Results (authors' own): 10x lower token use and 2.1x fewer tool calls than file-by-file exploration across 31 repos [8].
  • Supply chain: publishes OpenSSF Scorecard and SLSA 3 badges [8].

4.7 GitNexus (open source, non-commercial license)

What it is: a code graph of symbols, calls, dependencies and execution flows, used through MCP, a CLI or a web explorer [45].

  • Tools: query, context, impact, trace, detect_changes and rename [45].
  • Languages: 18 providers, including COBOL [45].
  • Tech: tree-sitter parsing and LadybugDB, an embedded graph database with vector support [45].
  • Multi-agent: one shared HTTP MCP server can serve several concurrent agents [45].
  • Watch-outs: PolyForm Noncommercial license; commercial use, PR blast-radius review and unified multi-repo graphs sit in the paid enterprise offering [45].

4.8 Joern (open source)

What it is: a platform that turns source, bytecode and binaries into code property graphs for vulnerability discovery and static analysis research [53].

  • Tech: CPGs stored in a custom graph database and mined with a Scala DSL [53]; v4.0.0 moved from overflowdb to flatgraph [53].
  • Origin: introduced for vulnerability discovery in C system code and the Linux kernel [15].
  • Stewardship: Harness acquired Qwiet AI (formerly ShiftLeft) in Sep 2025, and CPG creator Fabian Yamaguchi is now at Harness [43].
  • Watch-out: Harness's own docs call the CPG learning curve steep [87].

6. Use cases

6.1 Generative agents (AI coding agents)

The gap: coding agents rebuild context from scratch on every task with grep, glob and file reads [5].

  1. Answer codebase questions with fewer calls. CodeGraph cut tool calls by 88% in its own benchmark [7]; codebase-memory-mcp reports 10x lower token use [8]. Fits: CodeGraph, codebase-memory-mcp, Sourcegraph MCP.
  2. Localize and repair issues. RepoGraph improved all four SWE-bench systems it was plugged into (ICLR 2025) [90]. KGCompass reached 58.3% on SWE-bench Lite at about $0.2 per repair [10].
  3. Find hidden dependencies before editing. CodeCompass reached 99.4% on hidden-dependency tasks versus 76.2% for a vanilla agent [91].
  4. Refuse to invent missing code. A Transcend hackathon team's agent checks Orbit and asks for the real location when it cannot find a service [24].
  5. Edit in dependency order. The runner-up hackathon project maps every affected file and edits them in dependency order [24].
  6. Ground answers in architecture facts. Moderne Prethink gives agents verified service endpoints and dependencies instead of making them infer architecture [75].

Watch-out: the graph only helps if it is called. When CodeCompass's tool was used, coverage hit 99.5%; when skipped, 80.2% [11]. Assessment: deliver context through hooks or skills, not prompts alone.

6.2 Toil reduction campaigns

Definition: Software Engineering at Google defines a large-scale change as logically related changes that cannot be submitted as one atomic unit [92].

  1. Build the impact set before changing anything. Google's migration tooling follows Kythe references up to five hops from a field, then an LLM fills the accuracy gaps [57]. Across 39 migrations the LLM generated 74.45% of code changes, and developers estimated a 50% time saving [57].
  2. Run deterministic framework and dependency upgrades. OpenRewrite recipes transform LSTs, and Moderne runs them across thousands of repos [65].
  3. Open, track and merge fleet PRs. Batch Changes tracks every changeset until merged [64]. At Spotify, Fleetshift handles target selection, scheduling and tracking while the Honk agent edits code, and Fleet Management has merged more than 2.5 million automated PRs [93].
  4. Remove dead code and stale flags. Uber's Piranha has removed around two thousand stale feature flags and their code [94]. Meta uses Glean to find unused C++ includes and automate cleanup [59].
  5. See what is blocked. Moderne Changelog exposes ready, blocked and waiting work to agents through MCP [3]; Meta tracks API migration progress with Glean [59].
  6. Feed LLM migrations rich context. Airbnb's prompts included sibling tests, imports and component source [95]. It migrated nearly 3.5K test files in 6 weeks [95] against a 1.5-year manual estimate [96].

Scale context: around half of Spotify's pull requests have been automated since mid-2024 [97].

6.3 Automated code review tooling

  1. Show the blast radius beyond the diff. Greptile queries its graph for a changed function's dependencies and usage [63]. code-review-graph reports reachable callers, dependents and tests with a risk score [46].
  2. Pull cross-file definitions into the review. CodeRabbit maps definitions and references and finds files that often change together [38].
  3. Ground GitLab MR review in the SDLC graph. Compare the Market's Orbit-grounded reviewer matched about 70% of expected inline comments versus about 58% for RAG, which did worse than no added context [2].
  4. Mix deterministic findings into AI review. Copilot code review combines LLM analysis with CodeQL and ESLint [82].
  5. Select tests a change can reach. A hackathon team used Orbit's whole-codebase call graph to find the tests a change can reach [24]. Meta uses Glean for test selection [59].
  6. Cut noise with reachability. Harness uses Qwiet's reachability analysis to cut noise and prioritize real risk [43].
  7. Index diffs for review tooling. Meta indexes diffs into "diff sketches" that drive lint rules and notifications [59].

Watch-out: Compare the Market scored alignment with a golden set using an LLM judge on 79 MRs, which the authors call directional [12].

6.4 Knowledge graphs

  1. SDLC context graph. Orbit links merge requests, pipelines and vulnerabilities to projects and code [13]; engineers use it to trace changes and investigate incidents [98].
  2. Incident and reliability forensics. A financial services company traced a build-system outage to a CI job failing half the time [2].
  3. Code, docs and infrastructure in one graph. codebase-memory-mcp links docs, architecture decisions and Terraform or Kubernetes config to code [8].
  4. Architecture knowledge as data. Prethink emits FINOS CALM diagrams and an optional knowledge graph [76].
  5. Decisions and team knowledge. Potpie indexes decisions, source history, team knowledge and workflows [48].
  6. Facts that change over time. Graphiti gives each fact a validity window and traces it back to source episodes [20].
  7. Org-wide code fact store. Meta's Glean serves code navigation, search, docs and RAG for AI coding assistants [59].
  8. Mixed corpora. Graphify merges code, PDFs and images, and tags each edge as extracted, inferred or ambiguous [44].

7. Evidence quality

  • Mostly vendor numbers. Orbit, CodeGraph, Augment and codebase-memory-mcp all publish their own benchmarks [2, 7, 8, 40].
  • One public customer A/B test. Compare the Market compared baseline, Orbit, RAG and Orbit plus RAG on 79 real MRs [12].
  • Small corpora show little gain. Graphify's reduction was about 1x on a 6-file corpus versus 71.5x on 52 files [44].
  • Assessment: star counts track attention. Graphify passed 149k stars within about seven and a half months of its April 2026 creation [44], so treat stars as a weak proxy for production use.

8. Decision guide (Assessment)

Evaluation criteria

  • Precision: compiler-grade (SCIP, LST, CodeQL) versus tree-sitter heuristics.
  • Scope: code only, or code plus MRs, pipelines and deployments.
  • Freshness: per-commit or per-file-save updates versus scheduled re-indexing.
  • Access control: permission-aware results across repos.
  • Agent ergonomics: tool count and description size, since clients truncate long descriptions [72].
  • Deployment and license: self-hosting timing and commercial terms.
  • Cost per query: graph calls add latency and spend [12].

Recommended path

  1. Fix the eval harness first. Reuse Compare the Market's four-arm design: no context, graph, RAG and both, on real MRs [12].
  2. Pick the corpus layer. If code lives on GitLab, trial Orbit Remote; if it spans hosts, trial Sourcegraph. Keep codebase-memory-mcp or CodeGraph as the local, MIT-licensed baseline.
  3. Pick the campaign layer. Pilot Moderne on one JVM migration and measure merged PRs and blocked changes.
  4. Check licenses early. GitNexus is noncommercial [45], CodeQL CLI terms restrict private code [31], and Orbit uses the GitLab EE license [23].
  5. Confirm self-host dates. Orbit Self-Managed and Dedicated follow GA [2]; Sourcegraph Self Hosted is on request [22].

Next actions

  • Ask GitLab for the Orbit Self-Managed date and RBAC model.
  • Run the four-arm MR review eval on 50 to 100 internal MRs.
  • Shortlist one campaign (for example a Java or Spring upgrade) for a Moderne pilot.
  • Index two or three large repos locally with codebase-memory-mcp and CodeGraph as a free baseline.
